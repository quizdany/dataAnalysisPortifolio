# Data analysis portfolio: Rwanda development data

Three projects that use public data on Rwanda's economy, energy and poverty.

| Project | What it shows | Tools |
| --- | --- | --- |
| [Development indicators warehouse](development-indicators-sql/) | A PostgreSQL warehouse of 24 years (2000–2023) of World Bank data, with constraints, automated data quality checks, reusable views and CI | PostgreSQL, SQL (CTEs, window functions, views), Tableau |
| [Energy progress analysis](energy-analysis/) | 30 years of energy indicators: trends, three forecasting models compared, and a regression of emissions on renewables | Python, pandas, statsmodels, Prophet, Dash |
| [Poverty index prediction](poverty-index-prediction/) | Predicting sector-level Multidimensional Poverty Index from nightlight satellite data and population density | Python, ArcGIS Pro, scikit-learn |

Write-ups: [portfolio site](https://alhafizabaka.wixsite.com/my-site-1).
